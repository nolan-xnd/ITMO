# Дополнительный вопрос от практика

## Возможно ли отправить HTML форму с помощью GET в теле HTTP запроса? Попытаться реализовать.

Ответ: Стандартный HTML документ это не поддерживает. По итогу был написан простой сервер и клиент с формой, где отправка осуществляется с помощью GET, но только в URL адресе.
